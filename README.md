# HyroxPlanner-project

Projeto criado por: Carlos Vinicius

Descrição
--------
HyroxPlanner é uma aplicação simples do tipo CRUD (Create, Read, Update, Delete) pensada para gerenciar informações relacionadas ao Hyrox — uma competição de fitness que combina corrida e estações funcionais. A ideia é permitir o cadastro e o acompanhamento de atletas, eventos, treinos e resultados de forma prática e didática.

O que é um "CRUD de Hyrox"?
------------------------
Um "CRUD Hyrox" refere-se a um sistema que implementa as operações básicas de persistência (criar, ler, atualizar e apagar) sobre os recursos envolvidos no planejamento e na organização de treinos e competições Hyrox. Exemplos de recursos que esse projeto pode gerenciar:
- treinos realizados: especificações e dias.
- Eventos/Competições: data, local, descrição e categoria inscrita.

# HyroxPlanner-project

Projeto criado por: Carlos Vinicius

Descrição
--------
HyroxPlanner é uma aplicação simples do tipo CRUD (Create, Read, Update, Delete) pensada para gerenciar informações relacionadas ao Hyrox — uma competição de fitness que combina corrida e estações funcionais. A ideia é permitir o cadastro e o acompanhamento de atletas, eventos, treinos e resultados de forma prática e didática.

O que é um "CRUD Hyrox"?
------------------------
Um "CRUD Hyrox" refere-se a um sistema que implementa as operações básicas de persistência (criar, ler, atualizar e apagar) sobre os recursos envolvidos no planejamento e na organização de treinos e competições Hyrox. Exemplos de recursos que esse projeto pode gerenciar:
- Atletas: dados pessoais, categoria, histórico de participações.
- Eventos/Competições: data, local, descrição e atletas inscritos.
- Treinos: sessões programadas, exercícios e observações.
- Resultados: tempos, posições e métricas de desempenho.

Motivação e contexto

Sou estudante de Ciência da Computação (CC), atualmente no 2º período. Criei este projeto a partir de um entregável da disciplina Fundamentos de Programação da CESAR School, com o objetivo de praticar conceitos de programação, estruturas de dados e operações básicas de persistência.

Funcionalidades (exemplos)
--------------------------
- Cadastro de atletas, eventos, treinos e resultados.
- Listagem e busca de registros.
- Edição e remoção de registros.
- Fluxo básico para inscrição de atletas em eventos.
